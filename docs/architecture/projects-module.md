# Módulo de proyectos

`projects` consume la oportunidad ganada y contratos públicos de cotización,
acuerdo y cuentas por cobrar. No escribe tablas comerciales ajenas. Plantillas
publicadas y planes de activación son snapshots con hash; la materialización de
fases y tareas ocurre sólo después de los cuatro gates.

El proyecto no crea usuarios cliente, portal, facturas ni cobros. La proyección
para el portal futuro se mantendrá detrás de un puerto interno y no se expone
en esta fase.
